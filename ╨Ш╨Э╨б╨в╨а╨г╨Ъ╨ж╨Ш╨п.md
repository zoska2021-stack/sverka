# Сверка — офлайн-версия 2.2

Все файлы лежат в одной папке, без подпапок, поэтому их можно загрузить на GitHub прямо с телефона.

## Обновить сайт на GitHub
1. Распакуйте архив. Внутри 10 файлов приложения: index.html, sw.js, manifest.webmanifest, jszip.min.js, pdf.min.mjs, pdf.worker.min.mjs и 4 иконки icon-….png.
2. Откройте ваш репозиторий → «Add file» → «Upload files».
3. Выберите все 10 файлов сразу и нажмите «Commit changes». Файлы должны лежать в корне репозитория, рядом друг с другом.
4. Старые папки lib и icons, если они есть, можно оставить или удалить — они больше не нужны.
5. Подождите 1–2 минуты, пока GitHub обновит сайт.

## Установить на телефон
1. Откройте адрес сайта в Chrome при включённом интернете.
2. На стартовом экране приложение само проверит себя. Должна появиться надпись «✓ Готово к работе без интернета».
   Если написано «Офлайн-режим не готов», там же будет указано, каких файлов не хватает.
3. Когда всё готово: меню ⋮ → «Установить приложение» (или «Добавить на главный экран» → «Установить»).
4. Запускайте с иконки «Сверка».

На iPhone: Safari → «Поделиться» → «На экран „Домой“».

## Важно
- Данные (таблица, записи, подсказки) хранятся только на телефоне. При очистке данных браузера они пропадут, поэтому почаще нажимайте «Сохранить таблицу».
- Не загружайте в репозиторий саму таблицу и документы.
