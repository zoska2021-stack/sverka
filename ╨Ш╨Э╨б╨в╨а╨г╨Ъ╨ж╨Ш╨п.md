# Сверка — офлайн-версия 2.1

Приложение целиком состоит из файлов в этой папке. Таблица, записи и подсказки хранятся только в памяти телефона, никуда не отправляются. После первой установки интернет не нужен.

## Что работает
- Таблица: открыть .xlsx, журналы всех рабочих листов, касса «Рост МСК», долги, дивиденды.
- Документы: PDF-выписки банка, PDF-платёжки, PDF-чеки Сбербанка, выписки в Excel и CSV, чеки в Word.
- Подсказки, проверка дублей, запись пачкой, сводка с графиком, выгрузка .xlsx.

## Что пока не работает
- Фото, скриншоты и сканы (PDF без текста). Нужен PDF из банка.

## 1. Разместить приложение (один раз, бесплатно)
Приложение должно открываться по адресу https://, иначе телефон не даст установить его и работать офлайн. Проще всего через GitHub Pages:

1. Зарегистрируйтесь на github.com.
2. Нажмите «New repository», назовите, например, `sverka`, выберите Public, нажмите «Create repository».
3. На странице репозитория нажмите «uploading an existing file» и перетащите всё содержимое этой папки (index.html, sw.js, manifest.webmanifest, папки lib и icons). Нажмите «Commit changes».
4. Откройте Settings → Pages. В разделе «Branch» выберите `main` и `/ (root)`, нажмите Save.
5. Через 1–2 минуты появится адрес вида `https://ваш-логин.github.io/sverka/`.

В репозитории лежит только код приложения. Ваша таблица и документы туда не попадают.

## 2. Установить на телефон
- **Android (Chrome):** откройте адрес → меню ⋮ → «Установить приложение» или «Добавить на главный экран».
- **iPhone (Safari):** откройте адрес → кнопка «Поделиться» → «На экран „Домой“».

Дальше запускайте с иконки «Сверка». Интернет больше не нужен.

## 3. Обновления
Когда будет новая версия, замените файлы в репозитории на новые. Приложение подхватит обновление при следующем запуске с интернетом (иногда нужно закрыть и открыть его дважды).

## Важно
- Данные живут в памяти браузера телефона. Если очистить данные Chrome/Safari или удалить приложение, несохранённые записи и выученные подсказки пропадут. Регулярно нажимайте «Сохранить таблицу».
- Открыть index.html прямо из папки на телефоне не получится: нужен адрес https:// из шага 1.
